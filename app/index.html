Pengaturan Aplikasi Kak Jule (Konfigurasi Tanpa Edit Kode)

1. Konfigurasi Google Gemini AI
Digunakan untuk respon pintar AI, pembuatan cerita, dan penjawab kuis teka-teki.
2. Konfigurasi YouTube Live Chat
Mendukung ID Channel (UC...), handle (@nama), atau link live YouTube aktif.
Pemilik siaran yang berhak menjalankan perintah admin (!jule on/off dll).
3. Konfigurasi TikTok Live
Username akun TikTok streamer.
Dapatkan API Key gratis di tik.tools.
